## 2026-09-10：商品大圖自動輪播

- 大圖僅收錄有配圖的「商品情報／商品資訊」，最多六則，並沿用首頁分類篩選。卡表、活動、規則等其餘消息保留於最新動態。
- 多張商品圖每六秒切換，最後一張回到第一張；只有一張時不啟動計時。
- 選中的指示點為 28 點／dp 橢圓，以六秒從空逐漸填滿，不顯示數字；其餘指示點保持小圓點。
- 手動滑動後重新計時；離開首頁、App 進入背景、開啟商品詳情或首頁篩選時停止計時，返回後重新計時。
- 輪播資料更新時重設到第一張。iOS 減少動態效果設定會取消自動換頁的平移動畫。
- 驗證：兩版建置成功，Android 40 項既有測試通過；iOS 模擬器實際畫面確認大圖自動換頁與橢圓內部分填充，且下方仍保留活動／規則／卡表消息。Android 動畫尚未進行裝置視覺驗證。
