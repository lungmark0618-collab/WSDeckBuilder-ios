# WSDeckBuilder 介面規劃

設計方向：以 Apple 發表會的克制展示感為靈感。近黑背景、石墨灰表面、清楚的大標題與適量留白；用真實卡面呈現視覺焦點，用細微光影增加質感。這是風格詮釋，不是 Apple 官方設計或完整仿製。

## 功能與版面配置

| 畫面 | 使用者的目的 | 由上到下的配置 |
| --- | --- | --- |
| 首頁 | 看新情報、回到常用牌組 | 簡短介紹 → 常用牌組（有釘選才出現）→ 焦點商品 → 官方消息 |
| 圖鑑入口 | 選作品或跨作品找卡 | 常駐作品搜尋 → 全部卡片入口 → 已收藏 → 所有作品 |
| 卡片結果 | 找到卡片並加入牌組 | 作品名稱及搜尋 → 使用中的牌組 → 篩選摘要 → 卡片網格／清單 |
| 卡片詳情 | 理解能力、決定加入 | 卡圖 → 卡名及基本數值 → 中文能力 → 加牌與持有數；日文依外觀設定顯示 |
| 我的牌組 | 建立、找到與管理牌組 | 牌組數及建立按鈕 → 操作提示 → 封面、名稱、張數與顏色比例 |
| 牌組詳情 | 調整卡表與確認完成度 | 規則狀態 → 卡表／統計／缺卡 → 對應內容；分享與管理保留工具列入口 |
| AI 助手 | 隨時查規則與解答 | 保留全域入口及設定開關；具卡片／牌組情境的問題由對應詳情頁開啟 |
| 設定 | 管理偏好與資料 | 維持既有功能；後續可依外觀、資料、AI、說明分組，避免高頻操作藏在設定 |

## 本次已實作

- 首頁以明確的段落名稱與副標分開商品和公告，公告改為安靜的深色表面。常用牌組不再依賴新聞載入成功才能出現。
- 公告空白分清載入中、沒有資料與分類全被隱藏，提供重新載入或調整分類的入口。
- 圖鑑的全部卡片入口由最底部搬到頂部。作品卡片降低飽和度、增加文字空間，收藏按鈕擴至 44 點並提供語音標籤。
- 有牌組時直接顯示建立按鈕、牌組數與滑動管理提示；空牌組時提供建立及 QR 掃描入口。
- 牌組封面背景降低飽和度與強度、名稱容許兩行，讓卡面仍可辨識而資料更清楚。
- 底部導覽縮小圖示與容器高度，未選取項目降低亮度，加入選取狀態的輔助使用標記。

## 可持續使用的設計準則

1. 一個畫面只保留一個主要實心動作。建立是主要動作；匯入、分享、篩選依情境作次要動作。
2. 主內容左右維持 16 點，區塊間 24 點，同類卡片間 12 點。沿用現有 Spacing 與 Radius。
3. 文字採系統語意字級；頁首用 title2，區塊用 headline，說明用 subheadline 或 caption。避免整頁全部加粗。
4. 強調色用來表達選取或動作，卡片顏色用來表達作品、規則或分類；不要用大面積亮色競爭注意力。
5. 卡圖本身不重製。文字盡量放在穩定的深色面板，封面背後的圖像僅作輕量識別。
6. 空白、載入、失敗都要說明原因與下一步，不能只留一片黑底。

## 本次範圍與後續重點

本次實作集中於三個主要入口與共用導覽；卡片結果、牌組詳情、AI 及設定保留既有功能配置。上表包含後續延伸設計，不表示所有細節畫面均已重製。

後續值得獨立處理：全 App 淺色模式與使用者背景偏好的一致性、原生分頁容器以保留各分頁的瀏覽狀態、橫向／iPad 雙欄布局、牌組詳情的多項警告在大字級下的換行，以及 AI 浮動入口的 VoiceOver 操作。這些需要連同整體導覽與樣式驗證，不能只換顏色就視為完成。

## 第二版：克制的展示感

依使用者補充偏好調整：

- 首頁移除介紹段落，以「最新商品／值得期待。」作為單一展示主題。商品圖完整顯示，標題放在獨立區域；卡片高度會隨文字級距調整。
- 公告移除獨立卡框、寶石標記與彩色分類，改為文字層次與細分隔線。
- 圖鑑簡化成「探索作品」，作品名稱使用完整卡寬，收藏移至右下角，避免擠壓標題。
- 表面改近黑與石墨灰，作品色僅保留微弱染色；導覽選取以白色與淡底呈現。
- AI 浮動按鈕改為深色表面與淡色描邊，主要建立動作仍保留使用者的強調色。
- 保留實用資訊密度，不加入自動播放、裝飾動畫或大幅視差。

第二版已通過模擬器建置，並檢視首頁與圖鑑實際畫面。

## 背景自訂與首頁精簡

依後續需求，首頁只移除「最新商品／值得期待」兩行標題；商品大圖輪播、常用牌組與最新動態均保留；既有消息搜尋保留，引導說明同步更新。

設定 → 外觀 → 背景提供跟隨系統、淺色、深色、純黑、米紙、深海藍與自訂顏色。自訂顏色採不透明 RGB 儲存，重新開啟仍會保留；選色後依背景相對亮度決定系統明暗模式。首頁、圖鑑、牌組、導覽、篩選、消息詳情與 AI 使用共用環境配色；卡片圖片、QR 與掃描器保留本身必要的顏色。回復預設值同時重設背景及自訂色。
